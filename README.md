# Портфолио колориста — Seapovver Studio

Статический сайт без сборки и установки библиотек. Распакуйте папку, откройте `index.html` браузером. Исходная шапка, четыре контакта и полный подвал сохранены.

## Главная страница
- Нет строки поиска, заголовка с поиском и фильтров.
- Сетка почти на всю ширину экрана: 24 px от краёв на компьютере, 16 px на телефоне.
- Пять работ в ряд на широком экране; три при ширине до 1100 px; две до 700 px.
- Каждое превью — горизонтальный блок 4:3 (ширина:высота).
- Изображения любого формата центрируются автоматически, заполняют весь блок без полей и без растяжения. Неподходящие по пропорциям края обрезаются (`object-fit: cover`). Внутри проекта кадры показываются без обрезки в исходных пропорциях: первый крупно слева, второй и третий справа, остальные — в сетке по три.
- При наведении и фокусе с клавиатуры — умеренное затемнение, название и дополнительная строка по центру. Увеличения картинки и стрелки нет. На сенсорном экране подписи видны постоянно.

## Где что лежит

```text
index.html             — главная страница
project.html           — общий шаблон отдельных страниц проектов
projects.js            — ВСЕ РАБОТЫ: добавляйте и редактируйте их здесь
data.js                — только настройки исходной шапки и контактов
PROJECT-TEMPLATE.txt   — готовый блок новой работы для копирования
styles.css             — оформление
script.js              — логика; для добавления работ менять не нужно
images/                — превью и кадры
video/                 — ваши MP4
```

## Добавить свою работу — 5 шагов

1. В `images/` создайте папку с названием проекта, например `my-project`. Положите туда `preview.jpg`, `frame-01.jpg`, `frame-02.jpg`. Названия могут быть другими: важно, чтобы пути в коде совпадали с именами файлов, включая регистр.
2. Откройте `PROJECT-TEMPLATE.txt`, скопируйте весь блок.
3. Откройте `projects.js` и вставьте блок перед последней строкой `];`. Одна работа — один объект `{ ... },`. Запятая после объекта обязательна для следующей работы.
4. Заполните поля: уникальный `id`, название, подпись, превью, описание, кадры и видео. Для своих работ оставляйте `demo: false`.
5. Сохраните файл и обновите страницу браузера. Превью и отдельная страница появятся автоматически. Шестая работа начнёт новую строку, размер остальных не изменится.

### Поля проекта

| Поле | Что означает |
| --- | --- |
| `id` | Уникальная часть адреса, например `brand-film-2026`. Латиница, цифры и дефисы. Не повторяйте и не меняйте после публикации ссылок. |
| `title` | Название в центре превью и заголовок страницы проекта. |
| `subtitle` | Дополнительная строка под названием. `''` — без подписи. |
| `preview` | Путь к картинке главной сетки. Центрирование автоматическое. |
| `description` | Полное описание на странице проекта. Для абзацев используйте `\n\n`. Ссылки в тексте работают: адрес Instagram превращается в подпись `@nickname`, любой другой адрес — в кликабельную ссылку. Можно писать и просто `@nickname` без адреса. |
| `frames` | Первый кадр — крупный слева; второй и третий — справа; с четвёртого — сетка по три. Количество произвольное. |
| `video` | Настройки видеоплеера, либо `null`, если ролика пока нет. |
| `demo` | `false` для настоящей работы; `true` только для демонстрационных примеров. |

Структура одного блока:

```js
{
  id: 'my-project',
  title: 'Название проекта',
  subtitle: 'Рекламный ролик · бренд · 2026',
  preview: 'images/my-project/preview.jpg',
  description: 'Задача по цвету и описание вашей работы.',
  frames: [
    'images/my-project/frame-01.jpg',
    'images/my-project/frame-02.jpg',
  ],
  video: { provider: 'file', src: 'video/my-project.mp4', start: 0, end: 30 },
  demo: false,
},
```

Все существующие работы в `projects.js` оформлены одинаково: поля расположены в одном порядке и подписаны комментариями. Чтобы поменять порядок превью, переставьте целые блоки. Чтобы удалить работу, удалите весь её блок от `{` до `},`.

**Не нужно создавать новую HTML-страницу вручную.** Страница формируется автоматически из того же объекта по адресу `project.html?id=my-project`.

### Дополнительные подписи кадров

В `frames` можно использовать не только строки, но и объекты:

```js
frames: [
  'images/my-project/frame-01.jpg',
  {
    src: 'images/my-project/frame-02.jpg',
    alt: 'Портрет героя в тёплом вечернем свете',
    caption: 'Финальная цветокоррекция',
  },
],
```

### Видео

Плеер не запускается автоматически. Пути задаются относительно корня сайта.

- MP4: `video: { provider: 'file', src: 'video/my-project.mp4', start: 5, end: 25 }`. Положите файл в папку `video/`. Для совместимости — MP4 H.264/AAC. Фрагмент ограничивается указанными секундами. Лучше заранее обрезать ролик, чтобы не загружать зрителю лишние данные.
- YouTube: `video: { provider: 'youtube', id: 'ID_РОЛИКА', start: 15, end: 45 }`. ID — часть ссылки после `v=`. Это параметры встроенного плеера, а не защита полного видео от просмотра.
- Vimeo: `video: { provider: 'vimeo', id: '123456789', start: 10 }`. Поддержан старт; для точного конца используйте обрезанный MP4.
- Пока без видео: `video: null`.

YouTube/Vimeo требуют интернета и разрешения автора на встраивание. Проверяйте их на опубликованном сайте: через `file://` внешние плееры иногда недоступны.

## Демонстрационные материалы

`images/demo-*.jpg` — кадры из присланного референса, не заявленные работы Павла. Названия и описания — примеры. Перед публикацией удалите демонстрационные объекты из `projects.js` или замените их своими материалами и поставьте `demo: false`. Когда демонстрационных работ не останется, примечание на главной исчезнет автоматически. В текущих примерах видео не добавлено.

## Публикация

Чтобы не заменить первый сайт, создайте отдельный репозиторий GitHub. Загрузите содержимое папки в корень: `index.html` должен быть в корне репозитория. В Settings → Pages выберите Deploy from a branch → main → / (root). Для больших роликов удобнее видеохостинг.

Никаких внешних шрифтов, библиотек и аналитики. Внешние запросы — только встроенное видео при его использовании и ссылки контактов.

## Страница проекта — актуальная структура
Название и подпись по центру → короткое центрированное описание без заголовка → композиция из трёх кадров → обычная сетка по три → видеофрагмент.

Все кадры находятся в одной CSS Grid-сетке на всю ширину экрана, с внешними отступами 8 px, равными зазорам сетки. На компьютере всегда три равные колонки. Первый кадр занимает две колонки и два ряда слева; второй и третий — две ячейки справа друг над другом. Начиная с четвёртого кадры заполняют следующие ряды по три. Последний неполный ряд не растягивается: размер каждой ячейки остаётся таким же, как у двух кадров справа от главного.

Зазор везде одинаковый — 8 px: вертикально, горизонтально и под главным кадром. Обычные рамки имеют формат 16:9; главная почти 16:9 с поправкой на ширину зазора, чтобы границы всей сетки точно совпадали. Изображения целиком вписаны в рамки без обрезки и растяжения (`object-fit: contain`); при другом формате остаются тёмные поля. Полноэкранный просмотр открывает исходный кадр.

На телефоне — две равные колонки, главный кадр первым на всю ширину. Если кадр один, он занимает всю ширину. Если кадров два, на компьютере крупный слева, небольшой справа; пустые изображения не добавляются.

Подписи к кадрам, если заданы, остаются под изображениями. Текст, видео, навигация и главная страница не изменены.

В демонстрационных проектах оставлено по пять разных кадров из референса, без повторов внутри одного проекта. Это временная иллюстрация структуры, а не кадры реальных работ. Для своей работы замените `frames` и поставьте `demo: false`.

## Просмотр оригинальных кадров
Нажмите на любой кадр внутри проекта: откроется просмотр на весь экран. Картинка показывается целиком, без обрезки, перекодирования и дополнительного сжатия. Размер на экране подстраивается под устройство; исходное разрешение файла не меняется. В браузерах, где доступен Fullscreen API, включается настоящий полноэкранный режим; иначе просмотр занимает всё окно браузера.

- Стрелки слева и справа или клавиши ← / → — соседний кадр. После последнего кадра снова идёт первый.
- Плавное быстрое переключение: 160 мс. При системной настройке уменьшения движения анимация отключается.
- Esc или крестик справа сверху — закрыть. Фокус возвращается на выбранный кадр, положение страницы сохраняется.
- Для проекта с одним кадром стрелки скрываются.

Строки в `frames` автоматически используются и для сетки, и для полноэкранного просмотра:

```js
frames: [
  'images/my-project/frame-01.jpg',
  'images/my-project/frame-02.jpg',
],
```

Если нужно иметь лёгкую картинку для сетки и отдельный оригинал высокого разрешения, используйте объект:

```js
frames: [
  {
    src: 'images/my-project/frame-01-preview.jpg',
    original: 'images/my-project/frame-01-original.jpg',
    alt: 'Описание кадра',
  },
],
```

`original` необязателен: без него открывается тот же исходный файл, что задан в `src`. Чтобы показать настоящее качество, загружайте собственные оригинальные кадры. Текущие демонстрационные кадры вырезаны из скриншота референса и не содержат деталей сверх его разрешения.


## Приближение в полноэкранном просмотре
- `+` / `−` — увеличение и уменьшение, Круговая стрелка reset — исходный обзор целого кадра. Масштаб от 1× до 6× относительно вписанного изображения, а не физического разрешения файла.
- Колёсико мыши приближает к указателю; двойной щелчок переключает 1× / 2×.
- Увеличенный кадр можно перетаскивать мышью. На телефоне — двумя пальцами менять масштаб, одним перемещать; двойной тап переключает 1× / 2×.
- Клавиши `+`, `−`, `0` — увеличить, уменьшить, вписать. Стрелки по-прежнему переключают кадры, Esc закрывает просмотр.
- При смене кадра или повторном открытии масштаб сбрасывается. Увеличивается исходное изображение: новых деталей сверх разрешения файла не появляется.


## Интерфейс полноэкранного просмотра
Крестик закрытия расположен справа сверху, крестик и стрелки перелистывания — без рамок. При наведении значки слегка увеличиваются, а вокруг плавно появляется мягкая полупрозрачная подсветка. Стрелки центрируются в боковых полях между кадром и границей окна; на телефоне остаются доступными поверх кадра.

Вместо «Вписать» используется круговая стрелка reset с доступным названием и подсказкой. После открытия просмотрщика сверху кадра за 220 мс появляется подсказка о колёсике мыши (на сенсорном экране — о жесте двумя пальцами), на плавно растушёванном фоне. Через 3 секунды она плавно исчезает за 220 мс; при увеличении, сбросе масштаба или переключении кадра плавно исчезает за 220 мс и не повторяется до следующего открытия. Системная настройка уменьшения движения отключает анимации.

## Сравнение этапов обработки (v16)
Под видео каждого проекта расположен блок «Сравнение этапов обработки».
Окно — 60% ширины страницы (3/5), по центру; на телефоне — вся доступная ширина.
Пропорции окна всегда 16:9. Изображения любого формата заполняют окно без добавленных
чёрных полей через object-fit: cover: края могут обрезаться, геометрия не искажается.
Чёрные полосы, уже записанные в сам файл, этим способом не удаляются.
Исходные файлы не перекодируются, не уменьшаются и не обрабатываются фильтрами.
Для просмотра они масштабируются браузером под окно; при ширине окна меньше оригинала
это не показ пиксель-в-пиксель. Полноэкранное открытие у этого блока отсутствует.

### Как добавить шесть кадров
В projects.js у нужного проекта заполните comparison.frames. Пример:
```js
comparison: {
  frames: [
    { label: "Log", src: "images/prj-01/comparison/01-log.jpg" },
    { label: "Rec.709", src: "images/prj-01/comparison/02-rec709.jpg" },
    { label: "Primaries", src: "images/prj-01/comparison/03-primaries.jpg" },
    { label: "Color & skin Fix", src: "images/prj-01/comparison/04-fix.jpg" },
    { label: "Grade", src: "images/prj-01/comparison/05-grade.jpg" },
    { label: "Final", src: "images/prj-01/comparison/06-final.jpg" },
  ],
},
```
Папки и файлы создайте сами, положив туда оригинальные экспорты одного и того же кадра.
У всех проектов сейчас подготовлены шесть пустых src: реальные этапы не были переданы.
Пустой путь показывает «Кадр … пока не добавлен», не имитируя цветокоррекцию.
Меняйте label для любых подписей. Строка автоматически центрируется; на узком экране
переносится, не создавая горизонтальной прокрутки. Количество этапов можно менять.
Можно указать original вместо src, если отдельный путь ведёт к полноразмерному файлу.

### Управление
Стрелки в боковых полях за пределами кадра и нажатия на подписи переключают этапы без какой-либо анимации.
Клавиши ← / → работают только внутри блока, Home / End — первый / последний этап.
После последнего этапа стрелка переходит к первому. Никакого автоперелистывания нет.
Соседние кадры подгружаются заранее. Для ещё не загруженного оригинала может быть
небольшая задержка чтения файла; после загрузки он появляется целиком, без растворения.
Чтобы убрать раздел у конкретной работы: comparison: false.
